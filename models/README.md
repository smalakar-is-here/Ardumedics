# Model Weights — Download & Placement Guide

## Overview

You need to download **3 trained model files** from your Kaggle notebook outputs, then **export 1 NCNN model** for Raspberry Pi 5.

---

## Step 1: Download Models from Kaggle

Go to each Kaggle notebook → **Output** tab → find and download these files:

| # | File to Download | From Notebook | Inside Output Folder | Size |
|---|-----------------|---------------|---------------------|------|
| **1** | `best_nano.pt` | NB01 - YOLOv8n Pose Training | `nb01_outputs/best_nano.pt` | ~6.5 MB |
| **2** | `best_small.pt` | NB02 - YOLOv8s Pose Training | `nb02_outputs/best_small.pt` | ~22 MB |
| **3** | `best_medium.pt` | NB03 - YOLOv8m Pose Training | `nb03_outputs/best_medium.pt` | ~51 MB |

### How to Download from Kaggle

**Option A: From Kaggle Website (Manual)**

1. Open each notebook on Kaggle
2. Click the **Output** tab on the right panel
3. Find the `.pt` file in the file tree
4. Click the **download icon** next to the file
5. Save to your computer

**Option B: Using Kaggle CLI**

```bash
pip install kaggle

# Download NB01 output dataset
kaggle datasets download -d YOUR_USERNAME/ardumedics-nb01-nano-outputs
unzip ardumedics-nb01-nano-outputs.zip -d /tmp/nb01/

# Download NB02 output dataset
kaggle datasets download -d YOUR_USERNAME/ardumedics-nb02-small-outputs
unzip ardumedics-nb02-small-outputs.zip -d /tmp/nb02/

# Download NB03 output dataset
kaggle datasets download -d YOUR_USERNAME/ardumedics-nb03-medium-outputs
unzip ardumedics-nb03-medium-outputs.zip -d /tmp/nb03/
```

> **Note:** Replace `YOUR_USERNAME` with your Kaggle username and the dataset slugs with your actual output dataset names.

```bash

cp ~/Downloads/best_small.pt   models/best_small.pt
cp ~/Downloads/best_medium.pt  models/best_medium.pt
```

## Step 3: Export NCNN Model for Raspberry Pi 5

The NCNN model is **NOT** in the Kaggle output. You need to export it from `best_nano.pt`.

### Quick Export (on any machine with Python + ultralytics):

```bash
pip install ultralytics

cd models/
python3 -c "
from ultralytics import YOLO
model = YOLO('best_nano.pt')
model.export(format='ncnn')
"
```

This creates a `best_nano_ncnn/` folder next to `best_nano.pt` with:
- `model.ncnn.param` (~50 KB)
- `model.ncnn.bin` (~13 MB)

### Final folder structure after export:

```
models/
├── README.md
├── best_nano.pt               ← Downloaded from Kaggle NB01
├── best_small.pt              ← Downloaded from Kaggle NB02
├── best_medium.pt             ← Downloaded from Kaggle NB03
└── best_nano_ncnn/            ← Generated by export script
    ├── model.ncnn.param
    └── model.ncnn.bin
```

### Alternative: Export on Raspberry Pi 5 directly

If you can't export on your computer, you can do it on Pi 5:

```bash
# On Pi 5, after cloning repo and placing best_nano.pt:
pip install ultralytics
cd ~/Ardumedics/models/
python3 -c "
from ultralytics import YOLO
model = YOLO('best_nano.pt')
model.export(format='ncnn')
"
```

> **Warning:** This takes ~5-10 minutes on Pi 5. Prefer exporting on a computer with GPU.
